# 专家胜率驱动强化学习完整技术方案

## 一、设计目标

在现有 HMGS-DP 搜索算法和 CA-MOE 混合专家网络基础上，构建一套**资源受限、在线增量、专家独立**的强化学习框架。核心目标：
- 利用搜索树回溯中的胜率变化作为即时奖励，实现每步落子的正/反向学习。
- 专家网络独立更新，每个专家专注于自己擅长的局面，避免负迁移。
- 门控网络动态分配局面，并随专家能力进化而优化。
- 支持低成本风格迁移，通过权重边界收缩快速适配人类棋风。

## 三、详细模块设计

### 3.1 CA-MOE 专家网络

#### 3.1.1 网络结构
- **共享主干**：5~10 层残差卷积（输入 17 通道，输出 256 维特征图）。  
- **专家策略头**：每个专家一个 `Conv2d(256, 2) + GlobalAvgPool + FC` 输出 361+1 维动作概率。  
- **专家价值头**：每个专家一个 `Conv2d(256, 1) + GlobalAvgPool + FC` 输出标量价值。  
- **门控网络**：输入棋盘特征（全局平均池化或展平），经过两层 MLP 输出 softmax 权重（专家数 8~12）。  

#### 3.1.2 专家初始化
- 所有专家共享同一预训练权重（可使用 KGS 棋谱监督预训练）。  
- 门控网络初始随机，但可设计为基于局面特征的规则初始化（如开局时更偏好“开局专家”）。

### 3.2 搜索引擎集成点

#### 3.2.1 节点选择
- 在 `select_best_child` 中，当需要神经网络先验时，调用 CA-MOE 的推理接口。
- CA-MOE 返回：  
  - 各专家的动作概率分布（仅保留被激活的专家）。  
  - 各专家的价值估计。  
  - 门控权重（用于后续专家归因和备份）。
- 最终动作概率 = 加权平均（按门控权重）各专家的输出。

#### 3.2.2 价值备份与奖励记录
- 在 `_backup_value` 中，原有逻辑不变，但增加奖励记录：  
  - 沿着回溯路径（从叶子到根），记录每个节点的价值 `v_t`（存储在当前节点中，或临时数组）。  
  - 每步的奖励 `r_t = v_{t+1} - v_t`。  
  - 同时记录该步所使用的专家组合（门控权重最高的 K 个专家，K=2）。

#### 3.2.3 经验收集
- 每条经验包含：  
  - 状态特征（17 通道张量）  
  - 动作索引  
  - 奖励 `r`  
  - 下一状态特征  
  - 参与专家的索引列表及对应门控权重（用于后续更新时的归因）  
- 将经验存入**各专家对应的经验池**。每个专家维护独立 FIFO 队列，容量 5000。

### 3.3 专家独立学习模块

#### 3.3.1 奖励归因
- 若一步棋由多个专家参与（如门控权重 top‑2），奖励 `r` 按门控权重比例分配给这些专家。  
  - 例如专家 A 权重 0.7，专家 B 权重 0.3，则 A 获得 0.7r，B 获得 0.3r。
- 专家 C 未参与则获得 0 奖励（不更新）。

#### 3.3.2 策略更新（策略梯度）
- 对每个专家，定义损失：  
  $$L_{policy,i} = -\mathbb{E}_{(s,a,r_i)} \left[ r_i \cdot \log \pi_i(a|s) \right]$$  
  实际更新时，使用小批量样本，计算梯度并更新策略网络参数。  
  - 当 $r_i > 0$ 时，梯度方向增加该动作概率。  
  - 当 $r_i < 0$ 时，梯度方向减少该动作概率。  
- 添加熵正则项鼓励探索： $L_{entropy} = -\beta \cdot \sum_a \pi_i(a|s) \log \pi_i(a|s)$，$\beta$ 初始 0.01。

#### 3.3.3 价值更新（TD 学习）
- 对每个专家，TD 目标： $y = r_i + \gamma v_i(s')$  
- 损失： $L_{value,i} = \frac{1}{2}(v_i(s) - y)^2$  
- 使用在线梯度下降更新价值头。

#### 3.3.4 门控网络优化
- 门控网络的目标是让高价值专家在相应局面获得更高权重。  
- 辅助损失： $L_{gate} = -\sum_{i} g_i(s) \cdot \log \text{softmax}(v_i(s))$，即鼓励门控权重与专家价值对齐。  
- 也可直接使用策略梯度训练门控，但辅助损失更稳定。

#### 3.3.5 学习超参数
| 参数 | 值 | 说明 |
|------|----|------|
| 专家学习率 $\eta$ | 1e-4 | 策略头、价值头学习率 |
| 门控学习率 $\eta_g$ | 5e-5 | 门控网络学习率 |
| 折扣因子 $\gamma$ | 0.99 | |
| 熵系数 $\beta$ | 0.01 → 0.001 | 线性衰减 |
| 批大小 | 16 | 每个专家独立批大小 |
| 更新频率 | 每局结束后 | 每局进行 1 次更新（使用该局产生的经验） |

#### 3.3.6 经验优先级采样
- 每个专家池中，样本按 $|r_i|$ 排序，高绝对值的样本采样概率更高。  
- 实现方式：使用 SumTree 结构，或简单按概率采样。

### 3.4 风格迁移与权重边界收缩

#### 3.4.1 风格适配器设计
- 在每个专家的策略头之前插入一个轻量 MLP（输入为共享主干特征，输出为与专家头同维度的调整向量），实现风格的附加调制。  
- 或者更简单：每个专家训练一个独立的风格嵌入（小向量），与主干特征拼接后送入策略头。

#### 3.4.2 微调流程
1. 固定共享主干、专家主头参数。  
2. 仅训练风格适配器（或风格嵌入）。  
3. 使用行为克隆损失（交叉熵）拟合目标风格棋谱。  
4. 添加权重边界约束：  
   $$L_{constraint} = \lambda \sum_w \max(0, |w - w_{base}| - \epsilon)$$  
   其中 $w_{base}$ 是冻结部分的权重，$\epsilon$ 设为 FP16 的最小有效变化（例如 1e-7），$\lambda$ 为惩罚系数（如 1e-4）。  
5. 训练完成后，风格适配器可在推理时动态启用。

#### 3.4.3 在线风格调整
- 推理时，可通过额外输入控制风格强度（如温度参数），混合多个风格适配器的输出。

## 四、训练流程

### 4.1 数据流
1. 初始模型（共享主干+专家头）从 KGS 棋谱监督预训练获得。  
2. 门控网络随机初始化。  
3. 启动 HMGS-DP 自对弈（可与人机或自对弈）。  
4. 每步棋：
   - 调用 CA-MOE 获取专家输出 → 动作概率、价值、门控权重。  
   - 执行搜索 → 选择落子。  
   - 回溯时计算奖励，记录经验。  
5. 对局结束（达到终局）：
   - 将本局所有经验按专家归因后加入各专家经验池。  
   - 对每个专家，从自己的池中采样一个 batch，进行策略、价值、门控网络更新。  
   - 更新门控网络。  
6. 定期（例如每 100 局）评估与基线模型的对弈胜率，保存检查点。

### 4.2 训练加速技巧
- 使用 FP16 混合精度训练所有网络（利用 Tensor Core）。  
- 专家更新可并行：不同专家使用独立 GPU 流或分时更新。  
- 门控网络更新频率可降低（如每 10 局更新一次），减少干扰。

### 4.3 稳定性保障
- 梯度裁剪（最大范数 1.0）。  
- 学习率 warmup（前 1000 步线性增加至目标值）。  
- 使用 TD(λ) 替代简单 TD(0) 可加速价值收敛（λ=0.9）。  
- 定期将专家经验池与门控网络更新解耦，防止门控快速变化导致学习震荡。

## 五、验证方案

### 5.1 9×9 棋盘快速原型
- 目标：验证胜率驱动的正反向学习是否有效。  
- 实验组：使用本方案进行 1000 局自对弈训练。  
- 对照组：固定初始模型（不学习）。  
- 每 100 局对比一次胜率，预期训练组胜率明显提升（>55%）。

### 5.2 19×19 棋盘性能评估
- 训练 10,000 局后，与开源强 AI（如 KataGo 10b）进行 200 局对战，评估 Elo 变化。  
- 预期：在同等搜索规模下，棋力提升约 100~200 Elo。

### 5.3 风格迁移测试
- 收集 500 局“实地派”人类棋谱。  
- 微调风格适配器 1 小时，对比微调前后模型在相同局面下的动作分布（KL 散度），验证风格偏向是否明显。

## 六、资源需求与工程实现

### 6.1 硬件
- GPU：RTX 3060 12GB（或更高）  
- CPU：4 核以上  
- 内存：16GB

### 6.2 软件
- CUDA 11.0+  
- LibTorch 1.10+  
- 现有 SpaceGo 代码库（C++20）

### 6.3 关键代码模块
- `CA_MOE::forward()` 返回专家输出及门控权重。  
- `HMGSDP::backup_value()` 增加奖励计算与经验存储。  
- `ExpertTrainer` 类，管理每个专家的优化器、经验池、更新函数。  
- `StyleAdapter` 类，实现风格迁移微调。

## 七、总结

本方案将 **CA-MOE 专家分解**与 **胜率驱动的在线强化学习** 深度融合，实现了：
- 专家独立学习，避免负迁移，提高样本效率。  
- 利用 HMGS-DP 搜索树的价值变化作为即时奖励，无需等待对局结束。  
- 低成本风格迁移，通过权重边界收缩快速适配人类棋风。  
- 单 GPU 即可运行，资源友好。  

该方案填补了现有系统在轻量级强化学习方面的空白，为后续引入因果链网络等更高阶表征打下基础。实施后有望在有限资源下显著提升棋力，并实现可解释的风格化控制。
