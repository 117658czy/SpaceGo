# 多样性保护机制实现

## 核心设计

多样性保护机制是MiniGo AI系统的重要组成部分，旨在保护搜索过程中的新颖性，防止算法过早收敛到局部最优解。它通过多种策略确保搜索空间的充分探索，同时保持搜索效率。

- **新奇性价值函数**：对未合并分支给予特殊价值奖励，鼓励探索新颖区域
- **保护性探索保证**：确保所有区域都有最低探索概率，避免被忽视
- **被忽视分支识别**：自动发现长期未被探索的分支，优先分配资源
- **再发现机制**：对被遗忘的分支进行重新探索，找回潜在价值
- **资源智能分配**：根据分支的紧迫性和潜力动态分配搜索资源
- **多策略变体**：提供多种多样性保护策略，适应不同搜索场景

```python
class DiversityProtection:
    def __init__(self, gamma: float = 0.1, lambda_: float = 0.9, eta: float = 0.1,

        self.beta = beta  # 新颖性奖励系数
        self.alpha = alpha  # 合并奖励系数
        self.current_time = 0.0  # 当前时间
        self.protection_type = DiversityProtectionType.BASIC
        self.diversity_history = []  # 多样性历史记录
        self.resource_allocation_history = []  # 资源分配历史
```

## 算法实现

### 新奇性价值计算

计算节点的新奇性价值，对未合并分支给予特殊奖励：

```python
def calculate_novelty_value(self, node: HMGSNode) -> float:
    # 基础价值
    v_original = node.total_value / node.visit_count if node.visit_count > 0 else 0.0
    
    # 时间衰减函数：D(t) = exp(-λt)
    time_since_last_visit = self.current_time - node.last_visit_time
    time_decay = math.exp(-self.lambda_ * time_since_last_visit)
    
    # 回溯增强函数：B(k) = 1 + ηk
    backtrack_boost = 1 + self.eta * node.backtrack_count
    
    # 新奇性价值：V_novel = V_original + γ × (1 - P_merge) × D(t) × B(k)
    v_novel = v_original + self.gamma * (1 - node.merge_prob) * time_decay * backtrack_boost
    
    return v_novel
```

### 保护性探索概率

确保所有分支都有最低探索概率，防止被忽视：

```python
def calculate_protected_exploration_prob(self, node: HMGSNode, base_prob: float) -> float:
    # 确保最低探索概率
    protected_prob = max(base_prob, self.epsilon)
    
    # 对未合并分支给予额外的探索奖励
    if node.continuous_unmerged > 0:
        # 连续未合并次数越多，探索概率越高
        novelty_bonus = self.beta * (node.continuous_unmerged / 100.0)
        protected_prob += novelty_bonus
    
    return protected_prob
```

### 多样性权重调整

根据搜索结果的一致性，动态调整分支权重：

```python
def adjust_weights_for_diversity(self, node: HMGSNode, consistency_level: float) -> None:
    with node.mutex:
        if consistency_level > 0.9:  # 完全一致结果
            # 合并为1个，权重 = 3 × 原始权重 × 合并奖励系数
            node.visit_count *= 3 * (1 + self.alpha)
        elif consistency_level > 0.6:  # 部分一致结果
            # 保留2个，权重根据一致性程度调整
            node.visit_count *= 2 * (1 + self.alpha / 2)
        else:  # 完全不一致结果
            # 保留所有3个，各自获得新颖性奖励
            node.visit_count *= (1 + self.beta)  # β > α，确保新颖性奖励大于合并奖励
```

### 被忽视分支识别

识别长期未被探索的分支，优先分配资源：

```python
def identify_neglected_branches(self, nodes: List[HMGSNode], 
                              u_threshold: int = 5, 
                              t_threshold: float = 10.0) -> List[HMGSNode]:
    neglected_branches = []
    
    for node in nodes:
        if (node.continuous_unmerged > u_threshold and 
            (self.current_time - node.last_visit_time) > t_threshold):
            neglected_branches.append(node)
    
    return neglected_branches
```

### 再发现紧迫性计算

计算被忽视分支的再发现紧迫性，用于资源分配：

```python
def calculate_recovery_urgency(self, node: HMGSNode) -> float:
    # 连续未合并次数的影响
    unmerged_factor = node.continuous_unmerged / 100.0
    
    # 时间衰减的影响
    time_since_last_visit = self.current_time - node.last_visit_time
    time_factor = min(time_since_last_visit / 100.0, 1.0)
    
    # 结构重要性的影响
    structure_factor = (node.merge_prob + node.merged_into_prob) / 2
    
    # 计算总urgency
    urgency = (unmerged_factor * 0.5 + time_factor * 0.3 + structure_factor * 0.2)
    
    return urgency
```

### 资源分配策略

为被忽视的分支分配资源，基于紧迫性进行加权分配：

```python
def allocate_resources_to_neglected_branches(self, neglected_branches: List[HMGSNode], 
                                           total_resources: int) -> List[Tuple[HMGSNode, int]]:
    if not neglected_branches:
        return []
    
    # 计算总 urgency
    ranked_branches = self.rank_branches_by_urgency(neglected_branches)
    total_urgency = sum(urgency for urgency, _ in ranked_branches)
    
    if total_urgency == 0:
        # 平均分配资源
        avg_resources = total_resources // len(ranked_branches)
        allocations = [(node, avg_resources) for _, node in ranked_branches]
    else:
        # 按 urgency 比例分配资源
        resource_allocations = []
        remaining_resources = total_resources
        
        for i, (urgency, node) in enumerate(ranked_branches):
            if i == len(ranked_branches) - 1:
                # 分配剩余资源给最后一个分支
                allocation = remaining_resources
            else:
                # 按比例分配资源
                allocation = int(total_resources * (urgency / total_urgency))
                allocation = max(1, allocation)  # 至少分配1个资源
            
            resource_allocations.append((node, allocation))
            remaining_resources -= allocation
        allocations = resource_allocations
    
    # 记录资源分配历史
    self.resource_allocation_history.append({
        'time': self.current_time,
        'allocations': allocations,
        'total_resources': total_resources,
        'neglected_branches_count': len(neglected_branches)
    })
    
    return allocations
```

### 分支排序方法

根据再发现紧迫性对分支进行排序：

```python
def rank_branches_by_urgency(self, nodes: List[HMGSNode]) -> List[Tuple[float, HMGSNode]]:
    ranked_branches = []
    
    for node in nodes:
        urgency = self.calculate_recovery_urgency(node)
        ranked_branches.append((urgency, node))
    
    # 按 urgency 降序排序
    ranked_branches.sort(key=lambda x: x[0], reverse=True)
    
    return ranked_branches
```

## 多样性保护变体

### 基于历史的多样性保护（HistoryBasedDiversityProtection）

考虑历史多样性趋势，调整再发现紧迫性：

```python
class HistoryBasedDiversityProtection(DiversityProtection):
    def __init__(self, gamma: float = 0.1, lambda_: float = 0.9, eta: float = 0.1,
                 epsilon: float = 0.05, beta: float = 0.2, alpha: float = 0.1,
                 history_window: int = 10):
        super().__init__(gamma, lambda_, eta, epsilon, beta, alpha)
        self.history_window = history_window
        self.protection_type = DiversityProtectionType.HISTORY_BASED
    
    def calculate_recovery_urgency(self, node: HMGSNode) -> float:
        # 基本 urgency 计算
        base_urgency = super().calculate_recovery_urgency(node)
        
        # 历史趋势调整
        history_trend = 1.0
        if len(self.diversity_history) >= self.history_window:
            # 计算最近历史的多样性趋势
            recent_scores = [h['score'] for h in self.diversity_history[-self.history_window:]]
            if len(recent_scores) >= 2:
                # 计算多样性变化趋势
                trend = (recent_scores[-1] - recent_scores[0]) / len(recent_scores)
                # 如果多样性下降，增加 urgency
                if trend < 0:
                    history_trend = 1.0 + abs(trend) * 2.0
        
        return base_urgency * history_trend
```

```python
class DynamicDiversityProtection(DiversityProtection):

            self.adaptive_beta = min(0.5, self.adaptive_beta * 1.1)
            self.epsilon = min(0.2, self.epsilon * 1.2)
        # 如果多样性高，降低新颖性奖励和探索概率
        elif current_diversity > 0.7:
            self.adaptive_gamma = max(0.05, self.adaptive_gamma * 0.9)
            self.adaptive_beta = max(0.1, self.adaptive_beta * 0.9)
            self.epsilon = max(0.01, self.epsilon * 0.8)
    
    def calculate_novelty_value(self, node: HMGSNode) -> float:
        # 基础价值
        v_original = node.total_value / node.visit_count if node.visit_count > 0 else 0.0
        
        # 时间衰减函数：D(t) = exp(-λt)
        time_since_last_visit = self.current_time - node.last_visit_time
        time_decay = math.exp(-self.lambda_ * time_since_last_visit)
        
        # 回溯增强函数：B(k) = 1 + ηk
        backtrack_boost = 1 + self.eta * node.backtrack_count
        
        # 使用动态调整的参数
```

```python
class AdaptiveDiversityProtection(DiversityProtection):
    def __init__(self, gamma: float = 0.1, lambda_: float = 0.9, eta: float = 0.1,
                 epsilon: float = 0.05, beta: float = 0.2, alpha: float = 0.1):
        super().__init__(gamma, lambda_, eta, epsilon, beta, alpha)
        self.protection_type = DiversityProtectionType.ADAPTIVE
    
    def calculate_recovery_urgency(self, node: HMGSNode) -> float:
        # 连续未合并次数的影响，自适应调整权重
        unmerged_factor = node.continuous_unmerged / 100.0
        
        # 时间衰减的影响，自适应调整权重
        time_since_last_visit = self.current_time - node.last_visit_time
        time_factor = min(time_since_last_visit / 100.0, 1.0)
        
        # 结构重要性的影响，自适应调整权重
        structure_factor = (node.merge_prob + node.merged_into_prob) / 2
        
        # 节点深度的影响
        depth_factor = node.depth / 100.0
        
        # 子节点数量的影响
        children_factor = len(node.children) / 20.0  # 假设平均子节点数为20
        
        # 根据节点特性调整权重
        if node.visit_count < 10:
            # 访问次数少的节点，增加结构和深度权重
            urgency = (unmerged_factor * 0.4 + time_factor * 0.3 + 
                     structure_factor * 0.2 + depth_factor * 0.1)
        elif node.depth > 20:
            # 深层节点，增加深度和子节点权重
            urgency = (unmerged_factor * 0.3 + time_factor * 0.2 + 
                     structure_factor * 0.1 + depth_factor * 0.3 + 
                     children_factor * 0.1)
        else:
            # 普通节点，使用默认权重
            urgency = (unmerged_factor * 0.5 + time_factor * 0.3 + 
                     structure_factor * 0.2)
        
        return urgency
```

### 多准则多样性保护（MultiCriteriaDiversityProtection）

综合考虑多个多样性准则，计算更全面的多样性评分：

```python
class MultiCriteriaDiversityProtection(DiversityProtection):
    def __init__(self, gamma: float = 0.1, lambda_: float = 0.9, eta: float = 0.1,
                 epsilon: float = 0.05, beta: float = 0.2, alpha: float = 0.1):
        super().__init__(gamma, lambda_, eta, epsilon, beta, alpha)
        self.protection_type = DiversityProtectionType.MULTI_CRITERIA
    
    def calculate_diversity_score(self, nodes: List[HMGSNode]) -> float:
        if not nodes:
            return 0.0
        
        # 基于合并概率的多样性
        merge_prob_diff = 0.0
        count = 0
        for i in range(len(nodes)):
            for j in range(i + 1, len(nodes)):
                merge_prob_diff += abs(nodes[i].merge_prob - nodes[j].merge_prob)
                count += 1
        merge_prob_diversity = merge_prob_diff / count if count > 0 else 1.0
        
        # 基于访问次数分布的多样性
        visits = [node.visit_count for node in nodes]
        avg_visits = sum(visits) / len(visits) if visits else 0
        if avg_visits == 0:
            visit_diversity = 1.0
        else:
            visit_diversity = 1.0 - (sum(abs(v - avg_visits) for v in visits) / (len(visits) * avg_visits))
        
        # 基于深度分布的多样性
        depths = [node.depth for node in nodes]
        avg_depth = sum(depths) / len(depths) if depths else 0
        if avg_depth == 0:
            depth_diversity = 1.0
        else:
            depth_diversity = 1.0 - (sum(abs(d - avg_depth) for d in depths) / (len(depths) * avg_depth))
        
        # 基于子节点数量分布的多样性
        children_counts = [len(node.children) for node in nodes]
        avg_children = sum(children_counts) / len(children_counts) if children_counts else 0
        if avg_children == 0:
            children_diversity = 1.0
        else:
            children_diversity = 1.0 - (sum(abs(c - avg_children) for c in children_counts) / (len(children_counts) * avg_children))
        
        # 综合多样性评分
        diversity_score = (merge_prob_diversity * 0.3 + visit_diversity * 0.2 + 
                         depth_diversity * 0.2 + children_diversity * 0.3)
        
        return diversity_score
```

```python
class NoveltyFocusedDiversityProtection(DiversityProtection):
    def __init__(self, gamma: float = 0.1, lambda_: float = 0.9, eta: float = 0.1,

        backtrack_boost = 1 + self.eta * node.backtrack_count
```

```python
class ResourceOptimizedDiversityProtection(DiversityProtection):
    def __init__(self, gamma: float = 0.1, lambda_: float = 0.9, eta: float = 0.1,
                 epsilon: float = 0.05, beta: float = 0.2, alpha: float = 0.1):
        super().__init__(gamma, lambda_, eta, epsilon, beta, alpha)
        self.protection_type = DiversityProtectionType.RESOURCE_OPTIMIZED
    
    def allocate_resources_to_neglected_branches(self, neglected_branches: List[HMGSNode], 
                                               total_resources: int) -> List[Tuple[HMGSNode, int]]:
        if not neglected_branches:
            return []
        
        # 计算总 urgency
        ranked_branches = self.rank_branches_by_urgency(neglected_branches)
        total_urgency = sum(urgency for urgency, _ in ranked_branches)
        
        if total_urgency == 0:
            # 平均分配资源
            avg_resources = total_resources // len(ranked_branches)
            return [(node, avg_resources) for _, node in ranked_branches]
        
        # 优化资源分配：考虑节点潜力
        resource_allocations = []
        remaining_resources = total_resources
        
        for i, (urgency, node) in enumerate(ranked_branches):
            # 计算节点潜力得分：结合 urgency 和节点特性
            potential_score = urgency
            
            # 访问次数少的节点，增加潜力得分
            if node.visit_count < 5:
                potential_score *= 1.5
            # 深层节点，增加潜力得分
            if node.depth > 15:
                potential_score *= 1.3
            # 子节点多的节点，增加潜力得分
            if len(node.children) > 10:
                potential_score *= 1.2
            
            # 归一化潜力得分
            normalized_potential = potential_score / sum(urgency for urgency, _ in ranked_branches)
            
            if i == len(ranked_branches) - 1:
                # 分配剩余资源给最后一个分支
                allocation = remaining_resources
            else:
                # 按潜力得分比例分配资源
                allocation = int(total_resources * normalized_potential)
                allocation = max(1, allocation)  # 至少分配1个资源
                allocation = min(allocation, remaining_resources)  # 不超过剩余资源
            
            resource_allocations.append((node, allocation))
            remaining_resources -= allocation
        
        # 记录资源分配历史
        self.resource_allocation_history.append({
            'time': self.current_time,
            'allocations': resource_allocations,
            'total_resources': total_resources,
            'neglected_branches_count': len(neglected_branches)
        })
        
        return resource_allocations
```

## 多样性保护工厂

多样性保护工厂类，用于创建不同类型的多样性保护策略：

```python
class DiversityProtectionFactory:
    """
    多样性保护工厂类，用于创建不同类型的多样性保护策略

        创建多样性保护策略

            多样性保护策略实例

            return DiversityProtection(**kwargs)

        elif protection_type == DiversityProtectionType.HIERARCHICAL:
```

### 多样性评分

计算节点集合的多样性评分，用于监测搜索多样性：

```python
def calculate_diversity_score(self, nodes: List[HMGSNode]) -> float:
    """
    计算节点集合的多样性评分
    
    Args:
        nodes: 节点列表
    
    Returns:
        多样性评分（0-1）
    """
    if not nodes:
        return 0.0
    
    # 计算节点间的平均相似度
    total_similarity = 0.0
    count = 0
    
    for i in range(len(nodes)):
        for j in range(i + 1, len(nodes)):
            # 使用合并概率的差异作为相似度指标
            similarity = 1.0 - abs(nodes[i].merge_prob - nodes[j].merge_prob)
            total_similarity += similarity
            count += 1
    
    avg_similarity = total_similarity / count if count > 0 else 0.0
    
    # 多样性评分 = 1 - 平均相似度
    diversity_score = 1.0 - avg_similarity
    
    # 记录多样性历史
    self.diversity_history.append({
        'time': self.current_time,
        'score': diversity_score,
        'nodes_count': len(nodes)
    })
    
    return diversity_score
```
