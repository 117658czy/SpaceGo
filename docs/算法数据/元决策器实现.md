# 元决策器实现文档

## 1. 核心设计概述

元决策器是MiniGo AI系统中的核心组件，负责整合所有元决策功能，实现问题复杂度评估、算法策略选择、参数自治与调优、运行时监测与动态切换、经验积累与元学习等功能。

### 1.1 核心功能
- 实现问题复杂度评估
- 实现算法策略选择
- 实现参数自治与调优
- 实现运行时监测与动态切换
- 实现经验积累与元学习
- 支持多种元学习策略
- 实现自适应调整机制
- 支持复杂的决策逻辑
- 实现多维度性能评估
- 支持动态资源分配

### 1.2 设计原则
- **分层决策**：将决策过程分为多个层次，从问题评估到策略选择再到参数调整
- **自适应学习**：基于历史数据和当前状态动态调整决策策略
- **多维度评估**：从准确性、效率、鲁棒性、可扩展性和适应性等多个维度评估性能
- **动态资源分配**：根据策略性能和优先级动态分配资源
- **元学习驱动**：利用元学习技术不断改进决策能力

## 2. 主要数据结构

### 2.1 核心组件

#### MetaDecisionMaker类
- **核心属性**：
  - `problem_evaluator`：问题复杂度评估器
  - `strategy_selector`：策略选择器
  - `runtime_monitor`：运行时监测器
  - `meta_learning`：元学习组件
  - `current_strategy`：当前策略

  - `performance_metrics`：多维度性能评估指标
  - `decision_history`：决策历史记录

## 3. 核心算法实现

### 3.1 策略选择流程

#### 基本策略选择
```python
def select_strategy(self, game_state) -> str:
    # 1. 评估问题复杂度
    complexity_level = self.problem_evaluator.get_complexity_level(game_state)
    # 2. 选择最优策略
    strategy = self.strategy_selector.select_strategy(complexity_level)
    # 3. 更新当前策略
    self.current_strategy = strategy
    self.runtime_monitor.set_current_strategy(strategy)
    return strategy
```

#### 增强的策略选择
```python
def enhanced_strategy_selection(self, game_state) -> str:
    # 1. 评估问题复杂度
    complexity_level = self.problem_evaluator.get_complexity_level(game_state)
    
    # 2. 获取当前元学习策略
    meta_learning_strategy = self.meta_learning_strategies[self.current_meta_learning_strategy]
    
    # 3. 使用元学习策略选择最佳策略
    strategy = self.strategy_selector.select_strategy(complexity_level)
    
    # 4. 记录决策历史
    self.decision_history.append({
        "strategy": strategy,
        "complexity_level": complexity_level,
        "timestamp": len(self.decision_history)
    })
    
    return strategy
```

### 3.2 运行时监测与调整

```python
def enhanced_monitor_and_adjust(self, game_state) -> Optional[str]:
    # 1. 更新性能指标
    self.update_performance_metrics(game_state)
    
    # 2. 监测当前状态
    monitor_results = self.runtime_monitor.monitor(self.engine)
    
    # 3. 判断是否需要切换策略
    if self.runtime_monitor.should_switch_strategy(self.engine, game_state, self.current_strategy):
        # 4. 选择新策略
        new_strategy = self.enhanced_strategy_selection(game_state)
        
        # 5. 计算决策置信度
        complexity_level = self.problem_evaluator.get_complexity_level(game_state)
        confidence = self.calculate_decision_confidence(new_strategy, complexity_level)
        
        # 6. 记录元学习数据
        self.meta_learning.record_meta_data(
            complexity_level,
            new_strategy,
            monitor_results["mechanism_efficiency"],
            monitor_results["resource_usage"],
            self.strategy_selector.get_strategy_params(new_strategy, game_state)
        )
        
        # 7. 更新当前策略
        self.current_strategy = new_strategy
        self.runtime_monitor.set_current_strategy(new_strategy)
        
        return new_strategy
    
    return None
```

### 3.3 自适应参数调整

```python
def adaptive_parameter_adjustment(self, game_state) -> Dict:
    # 1. 获取当前策略参数
    params = self.strategy_selector.get_strategy_params(self.current_strategy, game_state)
    
    # 2. 根据性能指标调整参数
    for param_name, param_value in params.items():
        # 简单的自适应调整：根据性能指标调整参数
        adjustment = self.adaptive_params["learning_rate"] * (self.performance_metrics["accuracy"] - 0.5)
        params[param_name] = max(0.1, min(1.0, param_value + adjustment))
    
    return params
```

### 3.4 决策置信度计算

```python
def calculate_decision_confidence(self, strategy: str, complexity_level: str) -> float:
    # 基于历史数据计算置信度
    performance = self.meta_learning.get_strategy_performance(strategy, complexity_level)
    return min(1.0, performance)
```

## 4. 元学习策略

### 4.1 元学习策略类型

元决策器支持8种元学习策略：

| 策略名称 | 描述 | 适用场景 |
|---------|------|---------|
| supervised | 监督式元学习 | 有标注数据的场景 |
| reinforcement | 强化式元学习 | 需要通过奖励学习的场景 |
| transfer | 迁移式元学习 | 需要迁移知识的场景 |
| ensemble | 集成式元学习 | 需要综合多个策略的场景 |
| evolutionary | 进化式元学习 | 需要通过进化优化的场景 |
| online | 在线元学习 | 需要实时学习的场景 |
| offline | 离线元学习 | 可以批量学习的场景 |
| adaptive | 自适应元学习 | 根据性能自动调整的场景 |

### 4.2 自适应元学习实现

```python
def _adaptive_meta_learning(self, complexity_level: str, strategy: str, performance: float, resource_usage: float, parameters: Dict) -> None:
    # 自适应学习：根据当前状态选择最合适的元学习策略
    if performance > 0.9:
        # 性能好，使用监督式学习
        self._supervised_meta_learning(complexity_level, strategy, performance, resource_usage, parameters)
    elif performance < 0.5:
        # 性能差，使用强化式学习
        self._reinforcement_meta_learning(complexity_level, strategy, performance, resource_usage, parameters)
    else:
        # 性能一般，使用在线学习
        self._online_meta_learning(complexity_level, strategy, performance, resource_usage, parameters)
```

## 5. 资源分配策略

### 5.1 资源分配策略类型

元决策器支持4种资源分配策略：

| 策略名称 | 描述 | 适用场景 |
|---------|------|---------|
| equal | 平等资源分配 | 所有策略同等重要的场景 |
| performance_based | 基于性能的资源分配 | 需要优先分配资源给高性能策略的场景 |
| priority_based | 基于优先级的资源分配 | 策略有明确优先级的场景 |
| dynamic | 动态资源分配 | 需要根据性能和优先级动态调整的场景 |

### 5.2 动态资源分配实现

```python
def _dynamic_resource_allocation(self, strategies: List[str]) -> Dict[str, float]:
    # 动态调整资源分配
    resource_allocation = {}
    
    # 结合性能和优先级进行动态分配
    for strategy in strategies:
        # 1. 计算性能因子
        performance = self.meta_learning.get_strategy_performance(strategy, "medium")
        
        # 2. 计算优先级因子
        priority = {
            "full_hmgs_dp": 1.0,
            "enhanced_mcts": 0.8,
            "light_hmgs": 0.6,
            "light_mcts": 0.4,
            "greedy_best_first": 0.2,
            "minimax": 0.1
        }.get(strategy, 0.5)
        
        # 3. 结合性能和优先级
        resource_allocation[strategy] = performance * 0.6 + priority * 0.4
    
    # 4. 归一化
    total = sum(resource_allocation.values())
    if total > 0:
        for strategy in resource_allocation:
            resource_allocation[strategy] /= total
    else:
        # 总和为0，使用平等分配
        resource_allocation = self._equal_resource_allocation(strategies)
    
    return resource_allocation
```

### 5.3 资源分配执行

def allocate_resources(self, strategies: List[str]) -> Dict[str, float]:

def get_best_move(self, game_state) -> Tuple[int, int]:
    # 1. 确保使用当前最佳策略
    params = self.adjust_parameters(game_state)
    
    # 2. 设置参数到引擎
    for key, value in params.items():
        if hasattr(self.engine, f'set_{key}'):
            getattr(self.engine, f'set_{key}')(value)
    
    # 3. 调用引擎获取最佳落子
    return self.engine.get_best_move()

def initialize(self, engine):
    # 1. 设置引擎实例
    self.engine = engine

    # 1. 设置新的引擎实例

## 11. 总结与未来发展

### 11.1 核心优势
- **分层决策设计**：将复杂决策过程分解为多个层次，提高决策效率和准确性
- **多维度性能评估**：从多个角度评估性能，确保决策的全面性
- **动态资源分配**：根据策略性能和优先级动态分配资源，提高资源利用率
- **元学习驱动**：利用元学习技术不断改进决策能力，适应不同场景
- **自适应调整机制**：根据当前状态和历史数据动态调整参数和策略，提高适应性
