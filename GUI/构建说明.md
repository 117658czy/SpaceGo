# SpaceGo 维空弈 GUI 构建说明

## 环境要求
- Visual Studio 2022 (安装在 D 盘)
- CMake 4.2.3 (安装在 D:\源程序\cmake-4.2.3-windows-x86_64)

## 构建步骤

### 方法一：使用 Visual Studio 开发者命令提示符（推荐）

1. 打开 "Developer Command Prompt for VS 2022"
   - 在开始菜单中搜索 "Developer Command Prompt for VS 2022"
   - 或者在 Visual Studio 中：工具 → 命令行 → 开发者命令提示

2. 导航到项目目录：
   ```cmd
   cd e:\SpaceGo 维空弈\GUI
   ```

3. 运行构建脚本：
   ```cmd
   build_simple.bat
   ```

4. 等待构建完成

### 方法二：手动构建

1. 打开 "Developer Command Prompt for VS 2022"

2. 创建构建目录：
   ```cmd
   cd e:\SpaceGo 维空弈\GUI
   if not exist build mkdir build
   cd build
   ```

3. 配置 CMake：
   ```cmd
   "D:\源程序\cmake-4.2.3-windows-x86_64\cmake-4.2.3-windows-x86_64\bin\cmake.exe" .. -G "Visual Studio 17 2022" -A x64
   ```

4. 构建项目：
   ```cmd
   "D:\源程序\cmake-4.2.3-windows-x86_64\cmake-4.2.3-windows-x86_64\bin\cmake.exe" --build . --config Release
   ```

## 输出文件位置

构建成功后，可执行文件位于：
```
e:\SpaceGo 维空弈\GUI\build\Release\SpaceGo_GUI.exe
```
