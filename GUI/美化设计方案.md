# SpaceGo 维空弈 - GUI美化设计方案

## 🎨 设计理念

融合Sabaki的简洁专注与现代设计的精致细腻，打造专业、优雅的围棋对弈体验。

---

## 一、整体视觉风格

### 1.1 色彩系统（Sabaki风格+SpaceGo特色）

#### 主色调：深空蓝
- **主色**：`#2D4A6B` - 专业、沉静、科技感
- **辅助色**：`#4A90A4` - 清新、现代
- **点缀色**：`#F39C12` - 活力橙（用于提示）

## 二、棋盘设计（Sabaki风格升级）

### 2.1 棋盘视觉效果

#### 棋盘质感
```
┌─────────────────────────────────────────┐
│  [木质纹理+轻微噪点]                  │
│                                       │
│  ┌─────────────────────────────┐      │
│  │  ● ─ ● ─ ● ─ ● ─ ●        │      │
│  │  │   │   │   │   │        │      │
│  │  ● ─ ● ─ ● ─ ● ─ ●        │      │
│  │  │   │   │   │   │        │      │
│  │  ● ─ ● ─ ● ─ ● ─ ●        │      │
│  └─────────────────────────────┘      │
│                                       │
└─────────────────────────────────────────┘
```

#### 棋子视觉效果
- **黑子**：
  - 主体：`#1A1A1A` 到 `#333333` 径向渐变
  - 高光：左上角 `#555555` 半透明椭圆
  - 阴影：右下角 3px 模糊阴影
  - 边缘：1px 深灰描边

- **白子**：
  - 主体：`#FFFFFF` 到 `#E0E0E0` 径向渐变
  - 高光：左上角 `#FFFFFF` 柔和高光
  - 阴影：右下角 2px 淡灰阴影
  - 边缘：1px `#CCCCCC` 描边

### 2.2 交互效果

#### 悬停提示
```
鼠标移动到交叉点：
  ● 半透明预览棋子
  ● 大小：标准棋子的 80%
  ● 透明度：50%
  ● 淡入动画：150ms
```

#### 落子动画
```
落子时：
  1. 棋子从 0 缩放至 100%（EaseOut，150ms）
  2. 轻微上浮 2px 后回落（Bounce，200ms）
  3. 棋盘轻微震动（±1px，100ms）
```

#### 最后一手标记
```
在落子点显示：
  ● 小圆圈标记（半径 6px）
  ● 颜色：`#E74C3C`（红色）
  ● 半透明效果
  ● 脉冲动画：每2秒淡入淡出一次
```

## 五、动画效果

### 5.1 过渡动画

| 悬停效果 | 150ms | EaseOut |
| 落子动画 | 200ms | EaseOutBack |

- 粒子颜色：与棋子同色系
- 粒子大小：2-4px
- 消散时间：300ms

## 七、技术要点

### 7.1 渐变绘制
使用 GDI+ 的 `PathGradientBrush` 和 `LinearGradientBrush`

### 7.2 阴影效果
通过多次偏移绘制半透明图层模拟

### 7.3 性能优化
- 双缓冲渲染
- 只重绘变化区域
- 资源缓存（画笔、画刷、字体）
